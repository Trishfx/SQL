# Analyzing Motorcycle Parts

## Business Question
Calculating wholesale net revenue generated by each product line, broken 
down by month and warehouse.

## Dataset
- Source: DataCamp project — "Analyzing Motorcycle Parts"
- A `sales` table with 10 columns, including product line, warehouse, 
  transaction total, payment fee, client type, and date

## SQL Techniques Used
- Subquery, used to derive a `Month` label from a date range before 
  aggregating in the outer query
- `CASE WHEN` for manually bucketing dates into named months
- Aggregate functions (`SUM`) to calculate net revenue (total minus 
  payment fee)
- Multi-column `GROUP BY` (product line, month, warehouse)
- Filtering on `client_type = 'Wholesale'` to scope the analysis

## Key Question Answered
- How much wholesale net revenue did each product line generate, per 
  month, per warehouse?

## Notes
This is a smaller, single-query project focused on one specific 
business question. The subquery pattern used here — bucketing raw dates 
into named periods with `CASE WHEN` before aggregating — is a reusable 
technique for any time-based reporting question.
