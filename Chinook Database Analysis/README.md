# Chinook Database Analysis

## Business Question
Exploring the Chinook sample database — an 11-table relational database 
covering music albums, artists, tracks, customers, employees, and sales — 
to answer business questions around revenue, customer geography, and 
sales agent performance.

## Dataset
- Source: Chinook sample database (widely-used relational sample dataset 
  for practicing SQL joins across a realistic schema)
- 11 tables including: `artists`, `albums`, `tracks`, `genres`, 
  `media_types`, `customers`, `employees`, `invoices`, `invoice_items`
- Represents a digital media store: customers purchase tracks, invoices 
  are billed, and sales agents are tied to specific customer accounts

## SQL Techniques Used
- Multi-table joins (`INNER JOIN`, `LEFT JOIN`), including chains of 
  3–4 joins in a single query
- Subqueries (calculating and filtering revenue by country)
- **Window functions** (`SUM() OVER (PARTITION BY ...)`, 
  `RANK() OVER (PARTITION BY ... ORDER BY ...)`) for agent sales totals 
  and year-over-year performance ranking
- **Common Table Expressions (CTEs)** for structuring multi-step logic 
  before ranking
- Aggregate functions (`SUM`, `COUNT`, `ROUND`)
- Date filtering (`BETWEEN`, `LIKE`) and string concatenation for 
  full-name formatting
- `GROUP BY` / `ORDER BY` / `LIMIT` for top-N style questions

## Key Questions Answered
- Top 5 artists by number of albums released
- Most popular music genre among customers in Brazil
- Total company-wide revenue, and revenue specifically from the USA
  (solved two ways — direct aggregation and via subquery)
- Customer lists filtered by country
- Invoice details tied to customers and billing country
- Which employees work as Sales Support Agents, and which customers 
  each one is responsible for
- Full invoice-level detail joining customers, agents, and line items
- Invoice volume and total sales for 2009 specifically
- Track-level detail joined with artist, album, media type, and genre
- Total sales generated by each sales agent
- Which sales agent generated the most revenue in 2009
- **Sales agents ranked by total revenue, per year**, using a window 
  function over a CTE

## Notes
This project intentionally includes two different approaches to the same 
USA revenue question (direct aggregation vs. subquery) to demonstrate 
both techniques. The final query builds on an earlier one-off "top agent 
in 2009" question by generalizing it into a year-by-year ranking using a 
CTE and `RANK()`, showing how a single-year analysis can be extended into 
a repeatable, scalable pattern.
